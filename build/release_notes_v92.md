## V9.2：全量功能防呆审计修复

对已有功能做了一次「完善 + 防呆」全量审计（双路代码审计 + 逐条复核 + 离线/真实
Word/真实 API 三级验证），修复了一批真实可复现的缺陷。**离线测试 71 → 84 项全绿。**

### 沙箱与执行稳定性（P0/P1）

- **`raise SystemExit` 逃逸沙箱**：原检查未禁 BaseException 家族，run_code 的
  `except Exception` 兜不住——CLI 直接退进程，**GUI 里会终结工作线程，悬浮窗对
  Word 的操作整体无响应**。静态层禁止 + 运行层 `except BaseException` 兜底。
- **负索引静默写错位置**：`delete_block(-1)` 会因 Python 负索引删掉最后一块、
  `replace_block(-1, md)` 把内容写进最后一块。所有编辑原语统一索引校验、
  空内容拒绝、失效 Range 拒绝写入。
- **文档变短时块地图说谎**：用户删掉尾部段落后，失配块仍保留过时的活 Range，
  block_map 展示错误文本、后续编辑在错位内容上操作。现在失配块 Range 失活。
- **事务中途失败永久卡住**：一次编辑报错后撤销栈永久关闭、之后所有编辑都不
  入快照、再次开事务直接报错。rollback 先复位标志，引擎在编辑失败时主动回滚
  卡住的事务。
- **回滚「半成功」**：恢复快照时逐块写入失败曾被静默吞掉，文档停在半写缺块
  状态却报「已回滚成功」。现在失败即明确报错。
- **replace_text 静默吞修改**：原实现不改块 md，事务回滚会把之前的查找替换
  结果无声还原；且无论是否匹配都报成功。现在回写 md、真实返回命中/未命中。
- 步数守卫改为全程共享（原为「每条语句各 50000 步」，与文档承诺矛盾）；
  修正代码携带当前文档结构（失败轮可能已改了一半文档，按旧索引修复会错上加错）；
  session 记忆注入加固（限长限条、降权措辞）；**网络/HTTP 错误不再静默吞掉**
  （打包后无控制台，用户原本对失败一无所知）。

### 引擎与 GUI

- **打字档位在生成中无效**：切换速度的命令被排队，要等生成结束才执行。现在
  直接写属性，**立即对进行中的生成生效**。
- **「追加补充」无法中断**：补充生成不检查中断标志，中断按钮完全无效。已修复；
  且「追加补充」不再是死路（此前选择条被隐藏、普通发送被拦、只能干等 5 分钟
  超时）——选择条保留可随时改主意，Esc 退出追加模式回到选择条。
- **退出卡死**：中断选择等待最长阻塞 5 分钟，退出命令要等它才被处理。现在退出
  时先解除等待。
- **切文档场景**：用户在 Word 里切换活动文档后，内容原本会写进旧文档。现在
  每条命令前检查并自动重绑到当前活动文档（真实 Word 双文档验证通过）。
- **块地图不再暗自启动 Word**：只附加已运行的实例；Word 没开时明确提示。
- 生成中点「修订 / 预设 / 存档」原先会延迟到生成结束后才悄悄执行，现在即时
  拒绝并提示先中断。
- **settings.json 被手改坏（值类型错误）原先启动必崩且无恢复路径**：现在按
  键校验类型、非法回退默认。
- 开机自启注册表写入失败不再「假装成功」（复选框勾着实际没生效）；设置写盘
  失败会提示而不是静默丢失。
- 隐藏窗口停在已断开显示器上召回后不可见 → 召回时校验几何；隐藏态下改设置
  导致热键失联 → 无论可见性都重注册；热键被占用首次就会提示。
- 流式生成时上滚阅读不再被每个字符 chunk 拽回底部；消息气泡 200 条上限；
  连按两次 Enter 不再丢失第二条文本；输入 20000 字上限；输入法组合态 Enter
  不会误发送。
